# RI-251: 失敗したボスの宿題と新しい目標を比べる

対象 #647 / 親 #548。結論: **限定比較の仮説採用、本番統合保留**。人間のプレイ評価は未実施。

## 固定イベント

通常ランから隔離した純TS試作。seed `RI-251` は盤面識別子で乱数は使わない。前期の監査で証拠が4不足した継続可能な未達だけを、理由 `evidence-short` として次期へ1件持ち越す。ランが終了する敗北は持ち越さず、この試作は自動継続しない。

宿題は証拠4を終えると一度だけ解消する。同じ未達から宿題を重ねない。未解消の期間はペナルティを1回足し、解消した期間からは足さない。新しい目標は作業4、価値14で、受付期間を過ぎると取り逃す。1期間の処理は4。宿題を優先するとその期間は目標へ回らない。未対応の残リスクは、残証拠×期間ペナルティとして得点とは別に残し、開始直後の敗北にはしない。

盤面は目標の受付期間とペナルティだけが違う。持続は作業3期間、受付3期間、未解消ペナルティ5。露出は作業1期間、受付1期間、未解消ペナルティ3。閲覧は、未達理由、残証拠、解消条件、受付期間、ペナルティ、両方の得点と残リスクを選択前に示す。決定後の選択肢は空になる。

## 同条件比較

得点は、目標の価値から支払ったペナルティを引いた値である。残リスクは得点に含めない。

| 盤面 | 宿題優先 | 新目標優先 |
| --- | ---: | ---: |
| 目標が3期間残る | 14 | 9 |
| 目標が今期だけ | 0 | 11 |

目標が残る盤面では、先に証拠を終えてから目標14を取り、ペナルティ0で14になる。目標を先に取ると未解消の1期間で5を引き、9になる。どちらの順でも宿題は1件のまま解消する。目標が今期だけの盤面では、宿題を先にすると目標を取り逃して0、目標を先にすると14からペナルティ3を引いた11になり、証拠4と残リスク12が残る。残っていても敗北にしない。宿題優先が常に上位ではない。

固定2盤面の仮説比較であり、本番のボス継続の証明ではない。次は残リスク12を得点へ入れると、今期限りの目標でも宿題が上回るかを見る。

通常ランのボス、四半期継続、自動勝利、SPEC、保存、ruleset、固定トラック、WebGL停止契約へ接続しない。閲覧順で結果は変わらない。本番採用時は、継続できる未達理由と解消と残リスクを保存する別Issueに分割する。version 1の信頼済み内部JSONに比較の初期状態、入力列、得点の推移を含める。外部入力検証と通常保存互換は対象外。
