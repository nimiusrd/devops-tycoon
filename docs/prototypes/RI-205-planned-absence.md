# RI-205: 予定不在を先読みする編成

対象: #601。評価: **修正して継続、本番統合は保留**。#657の固定リリース試作から、予定不在の期首処理を`plannedAbsence.ts`へ抽出する。通常ランの編成UI・休職判定・保存・リプレイ・rulesetは変更しない。

## 予告と復帰の契約

既存ロスターの同じ人物IDへ、休暇・研修・出張の理由と、予告期0・開始期2・復帰期4を保存できる。`previewPlannedAbsence`で名前・担当・理由・開始・復帰・疲労休職を編成状態と合わせて確認する。最小試作は純TSの編成プレビューであり、通常編成画面への表示は本番統合時に追加する。

不在は半開区間`[start,end)`。開始時に元配置とAI配布を一度記録し、処理前に控えへ移す。不在中に配置・AIを変更しても処理対象には戻らない。予定終了時に同じ人物を復元し、再実行や翌期に復元を繰り返さない。

疲労休職は予定不在とは独立。休職解除は現行`recoverStamina`の回復閾値を使う。先に休職が回復しても予定終了までは不在。予定終了時にまだ休職中なら配置は控えを維持し、その後の回復でも自動で元配置へは戻さず再編成する。予定終了を理由に休職を解除しない。

休暇・研修・出張は期首処理では理由の違いのみで、理由だけでは能力や得点を増やさない。研修の将来能力は、下の固定戦略比較のなかで後継のレビュー増分としてだけ動かす。休暇と出張の別効果は付けない。

## 同条件の判断比較

#657の既存40工数、6期、主力m2・後継m1、seed `RI-205`で、通常準備・前倒し・代打育成を比較する。通常30工数、前倒し33工数、育成31工数。不在中成果は12/12/16、主力の消耗累計は12/18/12。前倒しは今の成果を増やすが体力を6余計に払い、育成は準備中の4工数と後継者の余力を将来の処理へ交換する。操作しない通常準備でも30工数を処理し、この試作には即時敗北を設けない。

理由・期間と休職の重なりを独立に表現できたため、モデルの再利用は可能。上の三点は初回の記録であり、次節では再計算しない。#603の代打実績は、この期首処理を参照する。採否は修正して継続のままとする。

## 将来能力・到着・不在の長さ

採否は変えない。評価は **修正して継続、本番統合は保留** のまま。本番採用の結論は出さない。この節は固定戦略の計算である。人間のプレイ評価はしていない。途中で研修するか、仕事の到着に合わせて処理を変える適応の証拠にはしない。判断の面白さは未検証のまま。初回の通常・前倒し・代打育成の三点は再計算しない。

資源は初回と同じ。seed `RI-205`、6期、レビュー仕事40、主力m2のレビュー64（処理6、スタミナ95）、後継m1のレビュー32（処理3、スタミナ70）。不在の開始は2期。処理能力は `floor(review / 10)`。研修は準備の1期に1回だけで、主力の余力3と後継の余力1を使う。将来能力はその期の終わりに後継のレビューへ足し、次の期から処理に出る。100を超えない。今回の0から20では上限に届かない。仕事40は指定した期に一度だけ入り、未処理は持ち越す。6期で打ち切る。不在は半開区間 `[2, 2+長さ)` で、その間の主力の処理は0、後継は残る。不在中の主力は毎期5まで回復し、上限を超えない。トレイト倍率と自然成長は足さない。初回の処理も `stats.review` と工数あたりスタミナ1なので、同じ式を使う。

二つの判断は期間の最初に固定する。

- 予定を見ずに進む: 予告があっても6期とも研修しない。
- 先に編成を変える: 不在の前の1期に研修する。不在が無いときも、1期に仕事が無いときも、この判断なら研修する。

優劣は総出荷で、多い方を上とする。同数は同点。スタミナ消費は記録するが、出荷が同じなら優劣を付けない。各表で動かすのはその要因だけ。条件、入力列、期間履歴、出荷、反転は `planned-absence-factor-comparison.json` にあり、対象テストが同じ関数の再計算と照合する。

対照は将来能力10、到着1期、不在の長さ4。見ずに進むが出荷30、不在中12、準備中9、主力スタミナ12、後継レビュー32。先に編成を変えるが出荷31、不在中16、準備中5、研修費用4、主力スタミナ12、後継レビュー42。初回の通常と代打育成の同じ項目と一致する。前倒しの33はこの入力に無い。

## 採否

固定戦略の上では、優劣が反転する位置は将来能力の増分7と8、不在の長さ2と3である。到着時期の1期から6期までは先に編成を変える判断が上のまま。この位置は本番の定数にしない。判断の面白さ、休暇と出張を研修と分けた効果、二つの要因を同時に動かした盤面は未検証。評価は **修正して継続、本番統合は保留** のまま。本番採用の結論は出さない。

次に解く不確実性: 研修の将来能力をレビュー増分7以下に固定したまま、仕事の到着を1期より遅くするか不在を長さ2以下にしたときに、予定を見ずに進む判断の優位が残るかは未検証。

通常ランの本番、UI、保存、リプレイ、rulesetへは接続していない。今回の要因比較は#603の代打実績へも接続していない。試作のJSONは本番セーブへ混ぜない。
