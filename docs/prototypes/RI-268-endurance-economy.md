# RI-268 耐久経営

対象 [#664](https://github.com/nimiusrd/devops-tycoon/issues/664) / 親 [#548](https://github.com/nimiusrd/devops-tycoon/issues/548)。**勝利後の耐久モードは見送り**。人間のプレイ評価は未実施。

初回の通常勝利から別の比較用ランを開始し、最大6期を比較した。達成後は次のボスから目標を立て、未達からの継続は通常の目標修正を使った。初回勝利までに得たレリックを引き継ぎ、耐久中の追加のボスレリックとメタ報酬は停止した。

## 比較条件

難易度 `easy`、標準シナリオ、初期予算60、試練・優先施策なし、カードの候補は全解放。同一seedでは初勝利の直前までの行動・盤面と耐久各期の乱数種を共有する。通常部分は余力重視で最大6期進め、未達修正は候補先頭を選ぶ。初回勝利しない例も記録した。固定seedは探索から選んだ事例で、勝率推定には使えない。

- 共通操作。編成で復職者・採用者を適性に応じて配置し、実働コーダーを確保する。スプリントは手札を順に試し、1,000msごとにペアレビュー、レビュー待ち6以上で割り込み、延焼まで15tick以下の炎上に消火を試す。ドラフト先頭、進化は `review-1` → `quality-1` → `review-2` の順に可能なら解放。決断イベントは即時採用・即敗北を避ける先頭肢、判定イベントは先頭で進む。店では購入しない。
- 出荷優先。空き枠と予算があり、採用後も残高が正なら採用する。採用しない休息は先頭カードを強化し、修正は `cut_scope` を優先する。
- 余力重視。稼働可能な人が2名以下で採用後も採用費1回分を超える場合に採用する。採用しない休息は対象チームの負債15以上かつシニア体力60以上で返済し、それ以外で回復。修正は `quality_pivot` を優先する。両方針とも優先修正の提示がなければ候補先頭を選ぶ。
- 予算条件。現在の繰越のみと、期首ごとに12を加算する比較を両方針で行う。加算は前期の達成・ボス突破・敗北に連動せず、既存の繰越上限の適用後、次期の最初の編成時に一度だけ行う。繰越対照も同じフレーム復元を通る。12は事前探索で観測したボス開始時の課金がおおむね6〜11だったことに基づく比較値。既存インフラ単価、採用費25、目標修正の費用は既存定義を使う。

達成判定に加えて、期末に採用費1回分以上の予算と配属済みの実働メンバー2名以上を確保できた期を安定期とした。比較では「観測できたレビュー数」「安定期の最長連続」「期末残高・信頼」「出荷対目標・未達KPI」「期首/期末の編成・体力・負債・デッキ」「行動と期末結果」を見る。レビュー前に敗北した期は完了数に含めず、部分出荷はログに残す。`bossInfraCharge` はボス開始時の実際の引き落とし。スプリント中のカードによる返金より前の値で、到達しなければ空欄になる。

`ri268:2` は初回勝利前に敗北したため、耐久の分岐は発生しなかった。6期に届いた2条件も、終盤はAI採用率などのKPIが未達だった。

- `ri268:10` の期首加算ありでは、Q3で出荷優先が採用して期末予算12・稼働4名、余力重視が見送りで37・1名。同じ期の出荷は6,267対6,582だった。余力重視はQ4に稼働2名へ戻り、安定期を1期記録した。Q6は稼働1名に低下した。Q8では採用へ切り替え、予算19・稼働2名で終了した。出荷優先の採用はこの例で人員不足を早く補ったが、その期の出荷増にはつながらなかった。
- `ri75j-easy-7` の期首加算ありでは、余力重視の出荷はQ5の5,701からQ8でも5,703を維持し、シニア体力は期末30.4から67.1まで傾向として回復した。一方で、Q3からQ7まで毎回同じ品質転換を選び、出荷目標は4,590から1,575に下がった。未達の原因もQ4以降ほぼAI採用率に固定された。選択の反復が残り、耐久期間の長さだけではプレイヤー価値を判断できない。
- `ri268:26` は両予算条件で出荷優先が1期長く進んだ。期首加算ありの監査のQ5では、スコープ縮小後にカードを強化した出荷優先が出荷5,341、品質転換後に体力を回復した余力重視が5,108。後者の方が期末に稼働人員を1人多く残したが、Q6の途中で燃え尽きた。複数の判断が一緒に変わる比較のため、個別操作の因果は判定していない。

## 見送り理由

6期に届いたのは追加給付ありの2条件で、安定は最長1期だった。通常ランの複数四半期でも資源と目標の調整があり、今回の固定方針の比較では、期間を延ばして固有の判断を増やせる根拠は得られなかった。
