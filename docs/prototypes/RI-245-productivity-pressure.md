# RI-245: PR数の要求と実得点を分けて比べる

対象 #641 / 親 #548。結論: **限定比較の仮説採用、本番統合保留**。人間のプレイ評価は未実施。

## 固定イベント

通常ランから隔離した純TS試作。seed `RI-245` は盤面識別子で乱数は使わない。現行の kpi-trap に同じ効果の別名イベントを足さない。要求は次の1スプリントだけに見え、対応は2つである。勝利種別の宣言は入れない。

要求はPR数4。見かけの指標はPR数、実得点は納品から手戻りと説明費用を引いた値である。PR数を要求以上にしても実得点には足さない。対応は1回で終わり、同じスプリントでもう一度分割してもPR数も得点も増えない。

分割して合わせる対応はPR数4。仕事が独立しているときは納品12、手戻り0。仕事が一連の流れのときは細切れの納品4と手戻り4になる。流れを説明して守る対応はPR数2、説明費用3。独立した仕事では納品6、一連の流れでは納品14になる。説明して要求を外しても敗北にはしない。

閲覧は、要求、現在のPR数、納品、手戻り、説明費用、実得点、見かけと実得点の名前、達成の有無、両方のPR数と実得点を示す。選択後も確定した内訳と両方の比較を残す。役立つ条件は独立した修正、不利な条件は一連の流れである。選んだあとの選択肢は空になる。

## 同条件比較

| 盤面 | 分割して合わせる | 流れを説明する |
| --- | ---: | ---: |
| 独立した修正 | 12（PR数4、達成） | 3（PR数2、未達） |
| 一連の流れ | 0（PR数4、達成） | 11（PR数2、未達） |

独立した修正では、数を合わせる12が説明の3を上回る。一連の流れでは、数を達成しても手戻りで0になり、説明の11が上回る。PR数の達成は実得点の高さを意味しない。どちらも追加の分割では点数は変わらない。

通常ランのイベント、自動勝利、SPEC、保存、ruleset、固定トラック、WebGL停止契約へ接続しない。閲覧順で結果は変わらない。本番採用時は、要求値、PR数、納品、手戻り、説明費用を保存する別Issueに分割する。version 1の信頼済み内部JSONに比較の初期状態、入力列、実得点を含める。外部入力検証と通常保存互換は対象外。
