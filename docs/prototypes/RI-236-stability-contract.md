# RI-236: 安定契約の確保と新機能投資を比べる

対象 #632 / 親 #548。結論: **限定比較の仮説採用、本番統合保留**。人間のプレイ評価は未実施。

## 固定盤面と契約

通常ランから隔離した純TS試作。seed `RI-236` は盤面識別子で乱数は使わない。顧客は RI-229 の keeper 1層で、人数は4。余力は4。期間は3で、3期間を終えると報酬は止まる。無期限の収入にはしない。契約は1件。毎期2を安定へ入れると報酬4が一度入る。2未満は違反で、軽い観測の損失は1、厳しい観測の損失は10である。機能は api、screen、billing で、完成に必要な作業は各4、完成価値は12。RI-228 の完成判定を使い、余った作業は他の機能へ移さない。敗北状態にはしない。

閲覧は確保枠、報酬、違反の損失、完成価値、現在の予算と残り作業を示す。閲覧では期間も予算も動かない。同じ期間の達成を二度報酬にしない。余力を全部安定へ入れても報酬は4のままである。

安定重視は毎期ちょうど2を契約へ入れ、残りを未完成の機能へ入れる。新機能重視は毎期すべての余力を未完成の機能へ入れ、契約は守らない。

## 同条件比較

予算は、完成価値、期間報酬、違反の損失を反映した期末の値である。

| 観測 | 安定の予算 | 安定の完成 | 新機能の予算 | 新機能の完成 | 新機能の違反 |
| --- | ---: | --- | ---: | --- | ---: |
| 違反が軽い | 24 | api | 33 | api, screen, billing | 3 |
| 違反が厳しい | 24 | api | 6 | api, screen, billing | 3 |

安定の予算推移は4、20、24で、報酬は3期間とも一度ずつ、違反は0である。軽い観測の新機能は11、22、33で、完成3つが違反1×3を上回る。厳しい観測の新機能は2、4、6で、同じ完成3つでも違反10×3のため安定の24を下回る。

固定2観測の仮説比較であり、本番の継続課金の証明ではない。次は確保枠、期間報酬、違反損失の感度を見る。

## 本番境界と検証

通常ランの予算、信頼、自動勝利、SPEC、保存、ruleset、固定トラック、WebGL停止契約へ接続しない。継続収入は3期間で止める。閲覧順で結果は変わらない。本番採用時は契約期間と、期間内の報酬を一度に限る保存を別Issueに分割する。version 1の信頼済み内部JSONに比較の初期状態、入力列、予算推移を含める。外部入力検証と通常保存互換は対象外。

`stability-contract-comparison.json` に観測、初期状態と入力列、予算推移を記録した。対象ユニット、毎入力のJSON保存再開と再生一致、型チェック、lint、format:checkを検証する。UI/Pixiの変更はなく、E2Eとgalleryは対象外。
