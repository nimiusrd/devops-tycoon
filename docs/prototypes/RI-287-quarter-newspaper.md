# RI-287: 保存された四半期KPIの社内新聞

対象: #683 / 親 #548。結論: **保存済みKPIを読む表示を限定採用。物語としての手応えの評価は保留**。人間のプレイ評価は未実施。PRのマージを企画全体の採用や面白さの証明としない。

## プレイヤーの判断と範囲

プレイヤーは出荷と士気の達否を同じ期の実績・目標で振り返り、次期の目標修正や継続を選ぶ。新聞の閲覧に資源消費はなく、成果・信頼・報酬・勝敗・目標修正のルールは追加しない。

`QuarterReviewScreen` の閉じた `details` に2本だけ載せる。既存の `result-details` の44px操作・フォーカス表示、既存の文字色tokenを再利用する。新tokenや共通CSS変更はない。直近人物の成長・休職を語る `quarterReviewVoicesView` とは文章を共有せず、新聞は保存KPIの見出しと数値根拠に限定する。

参照元は `QuarterTrendSnapshot.kpis` の `delivery` と `morale`。表示中の `quarterNumber` と完全一致する履歴を選ぶ。保存済みstatusを表示し、達否を再計算しない。全社集約、現在のレビュー・目標・所持レリック・人物、別期の実績、前後差は記事の代用にしない。投資・採用・育成の時点や因果が未記録なので、それらの成功や危機脱出は書かない。士気未達を出荷達成の結果とも断定しない。

履歴がないときと、当該期のKPIがないときは理由を分ける。実績0と目標0は欠測にしない。入力を変更しない純粋表示モデルとし、保存形式・ruleset・シミュレーション・乱数は変更しない。

## 固定表示条件と技術検証

表示fixtureはseed `ri287-newspaper`、easy、同じ初期資源を使用する。戦略の優劣を計算する試作ではない。入力と期待結果はユニット/E2Eに保存する。

| 条件 | 見出し・根拠の期待 |
| --- | --- |
| 出荷120 / 100達成、士気30 / 40未達 | 出荷達成と士気未達を独立表示 |
| 出荷0 / 100未達、士気60 / 40達成 | 出荷未達を残し士気だけ達成 |
| 両方未達 | 成功の見出しへ言い換えない |
| 当該期履歴なし、別期・現行レビューあり | 当該期の履歴欠損を明記 |
| 当該期の士気KPIなし | 士気KPI欠損を明記、現在値で補完しない |
| 保存再開・リプレイ復元 | 同じ期の記事と数値が一致 |

対象検証は表示モデルとレビュー接続のunit、型チェックを含むbuild、lint、format:check、対象E2E。E2Eでは320×568、390×844、768×1024、1024×768、1440×900と390幅のreduced motionを確認する。実WebGLの準備完了後に表示fixtureへ進み、横溢れ、Enter/Space開閉、フォーカス、閲覧による状態不変、次期操作を検証する。320幅と1440幅のスクリーンショットを目視する。既存人物コメント・リプレイジャンプ・レビュー読込の対象E2Eも確認する。Pixi実装・共有token・複数画面の変更がないため、Pixi画像更新とgalleryは対象外。

実行結果: 対象unit 39件、build、lint、format:checkは成功。E2Eは新聞6件とリプレイ遷移4件（Chromium / WebKit）が最終実行で10件成功し、人物コメント6件・レビュー読込1件も成功した。320幅と1440幅の画像に横溢れや文字の欠落がないことを目視した。初回の開発サーバー・2 workerでは初期描画前に時間切れとなり、本番ビルド・1 workerでも共通fixtureのWebGL待機5秒が不足したため、新しい新聞テストだけ準備完了を30秒まで待つよう修正した。負荷下で時間切れとなった既存WebKitリプレイ1件も再実行で成功した。これらは表示・操作の技術検証であり、人間の手応え評価ではない。

## 人間評価の残課題と再判断条件

人間評価は未実施であり、「会社の歩みが感じられる」「次期の方針選びに役立つ」とはまだ判定しない。Issueはopenを維持する。

次は同じseed・保存データ・資源・操作列の四半期レビューを、新聞を閉じた条件と開いた条件で人間が比較する。各条件で実際の判断、出荷の成果、士気の状態、払った代償として記録から説明できる範囲、次期に変えたい条件を記録する。見出しから因果を誤読しないか、人物コメントと重複して感じないか、次期操作が探しやすいかを確認する。

評価後に採用・再試作・見送りをIssueへ記録する。重複や誤読が残れば見出し/配置を再試作し、方針選びに寄与しなければ表示を見送る。採用・投資の出来事を増やす場合は、日時・対象・結果の追跡可能な記録を先に設計する別の作業単位とする。
