# RI-176: 予約した非常手順

対象 #572 / 親 #548。結論: **限定比較の仮説採用、本番統合保留**。人間のプレイ評価は未実施。

## 固定盤面と操作

通常ランから隔離した純TS試作。seed `RI-176` は盤面識別子（乱数なし）。期末6、集中力6、出荷は利用可能集中力2で価値9、手動の火消しは利用可能集中力2で障害1件を消す。予約は利用可能集中力2を予約口座へ移して手順を武装する。予約口座は出荷にも手動火消しにも使えない。クールダウンは置かず、自動発動は1回だけ。発動後の再武装は拒否する。

各tickは、公開された到着、予約手順、手動、損失計上の順で解決する。閲覧やフレーム進行では乱数もtickも発火もしない。損失は解決後の残件数×5。到着は平穏がtick4に1件、炎上がtick2に2件、対象なしがtick2に2件で火消し不能。

自動発動の条件は武装中、未発動、障害2件以上、対象あり、予約集中力2。対象がないときは保留にし、予約集中力を減らさない。保留中は同じ条件を毎tick再判定するが、消費も発動もしない。解除は計画中（tick 0）か保留後だけ全額を利用可能口座へ戻す。条件待ちの任意解除と、発動後の解除は拒否する。

比較方針は公開情報だけを使う。予約する戦略は最初に武装する。対象がある残件は手動で消し、残件がなければ利用可能集中力が2を超えるときだけ出荷して手動枠を1回残す。対象がないときは出荷に使ってよい。

平穏では予約手順が条件未達のまま残り、ロックした2を出荷に使えない。予約なしの出荷18が、予約した出荷9を上回る。炎上では同じ出荷9に対し、予約なしは2件を別tickで消して残件の損失5が付く。予約ありはtick2に自動火消しの後で手動火消しがもう1件を消し、損失0。差引9が4を上回る。同じ方針でも、条件が来るかどうかで予約の優劣が入れ替わる。

対象なしは自動発動せず予約集中力も減らない。維持したままでは差引-32、保留後の解除で返還分を出荷に使い-23。損失50は同じで、戻った集中力の出荷9が差になる。

## 要因を一つずつ動かした比較

固定戦略の計算である。人間のプレイ評価はしていない。固定係数の比較を、本番の面白さやプレイヤーが境界を見て選べることの証明にはしない。本番採用の結論は出さない。

資源は初回と同じ。seed `RI-176`、期末6、集中力6、出荷は利用可能集中力2で価値9、手動の火消しは利用可能集中力2で障害1件を消す。損失は解決後の残件数×5。到着は平穏がtick4に1件、炎上がtick2に2件、対象なしがtick2に2件で火消し不能。基準は予約額2、条件2件、自動が先。動かした要因以外は変えない。予約する戦略は最初に武装する。手動対応は武装しない。差引は出荷価値−障害損失。数値は本番定数ではない。

対象を消せる盤面で残件が無いとき、利用可能集中力が2を超える場合だけ出荷して手動枠を残す。対象なしは2以上なら出荷する。手動が先でも、条件件数を残すために火消しを遅らせない。

手動対応の差引は要因に依存しない。平穏18、炎上4、対象なし-23。

平穏と対象なしの反転は0と1のあいだ。予約額0ではどちらも自動が差を作らず、ロックが無いので手動と同点になる。予約額1は利用可能が5になり、2を超えるあいだ出荷して1が残る。平穏ではその1で火消しできず、障害が3tick残って差引3。対象なしは出荷18で差引-32になり、手動の-23を下回る。

炎上の反転は2と3のあいだ。予約額2は初回と同じで、出荷9のあと自動と手動が同じtickで2件を消し差引9。予約額3は出荷で利用可能が1になり、自動が1件消したあとの手動火消しが拒否される。残件がtick2から6まで損失25、差引-16。予約額4は出荷せず、自動と手動で損失0だが出荷も0で差引0。手動の4は上回らない。差引は3の-16より戻るが、優劣は戻らない。5と6は残件を消せない。予約額0の炎上は消費0で1件消すが、残った集中力2は手動枠のまま出荷されず、差引は予約額2と同じ9である。

炎上の反転はこの順序だけ。予約する入力列は両順序で同じ。手動が先だとtick2の火消しが2件を1件にし、条件2件を外して自動がskipになる。残件の損失で差引-16。自動が先だと同じ入力で差引9。平穏は1件なのでどちらの順でも自動は条件未満。対象なしは手動火消しができず差引が動かない。

`emergency-procedure-factor-comparison.json` に条件、規則、入力列、解決順、差引、優劣、反転を残す。対象テストが再計算し、予約額2・条件2件・自動が先の行が初回JSONの手動と予約に一致することを照合する。初回の比較JSONは更新していない。解除する戦略は再出力しない。

次に解く不確実性: 手動先で炎上の予約が差引-16まで落ちるのは火消しを遅らせない固定戦略であり、条件2件を残すために手動を1tick遅らせると予約側へ戻るかは未検証。

この要因比較は本番採用の判断を変えない。仮説は限定比較の採用のまま、本番統合は保留。
