# RI-284 文化が残るオフィス（#680）

## 判断と範囲

プレイヤーが所持文化の効果を壁の掲示と説明から振り返り、次のランで別の文化を選ぶか考えられるようにする。#537 のオフィス差分の最小単位として、既存の `small-pr` だけを表示する。

最小表示は採用。新しい能力・獲得ルール・バランス変更はない。個性の読み取りや再挑戦動機が改善するという体験仮説は、人間のプレイ評価が未実施のため未判定とする。PR のマージを体験仮説の採用根拠にしない。Issue は開いたまま評価を続ける。

## 表示の契約

- 正本は表示中の `state.relics` と `useReplayContent.resolveRelic`。`officeCultureView` から SVG の title と HTML の名前・効果・説明を生成する。
- 初回は左壁の1枠を `small-pr` 専用にする。他の文化を何個・どの順序で所持しても入れ替えず、重ねない。所持していなければ空の壁に戻る。他文化の所持一覧は既存のレリック欄に残す。
- HTML 説明は既存のラン詳細内のレリックから Enter/Space またはクリックで展開できる。常時の説明行を追加しない。文字・効果は記録定義から取得し、色や紙の形だけを情報源にしない。
- 描画は `SprintScreen → Board → OfficeRoom` の静的 SVG と透明な実 WebGL の合成。人物・タスク・ヒット座標・警告・最低盤面寸法は維持する。SVG の壁内イラスト座標は局所値。共有色は `visualTokens.ts` の `officeCulture` を正本にする。
- 保存から再開・次スプリントでも所持から再導出する。表示状態を保存しない。新しいランに前ランの掲示を持ち越さない。
- リプレイは選択した離散キーフレームの所持と記録定義で説明する。現在のランや現在の効果へ差し替えない。定義のない旧 v1 は ID と欠損説明のみ。スナップショット内の欠損も resolver のプレースホルダーを使う。現行 import は不完全な v2 スナップショットを拒否するため、その欠損は表示モデルの unit で検証する。
- 現行のリプレイは動的スプリント盤面を保存していない。存在しない盤面や当時の配置を再構成せず、HTML 説明のみを表示する。将来盤面を記録する場合も同じ表示モデルを渡す。
