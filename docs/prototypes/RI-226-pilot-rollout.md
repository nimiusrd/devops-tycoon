# RI-226: 試験1チームと即全社を、展開・中止の時期で比べる

対象 #622 / 親 #548。結論: **限定比較の仮説採用、本番統合保留**。優劣が反転する位置は要因比較に記録した。人間のプレイ評価は未実施。本番採用の結論は出さない。

## 固定盤面と段階導入

通常ランから隔離した純TS試作。seed `RI-226` は盤面識別子で乱数は使わない。チームは pilot、north、south。基礎出荷は各5。期間は3。試験は pilot だけに効果を足し、north と south は基礎のまま。全社化しても効果は各チームへ一度だけ足し、pilot に重ねない。試験を経て全社化する費用は2で、一度だけ払う。試験を一度も経ずに初回から全社へすると、盤面の一斉事故を一度だけ引く。試験期間の観測は pilot 出荷と基礎の差であり、差引には足さない。因果効果とは扱わない。敗北状態にはしない。

即全社は3期間とも全社。展開は試験のあと2期間全社。中止は試験のあと効果を外す。

良い効果は効果+4、一斉事故0。悪い効果は効果-3、一斉事故0。一斉事故は効果+4、事故20。

## 同条件比較

| 盤面 | 即全社 | 展開 | 中止 |
| --- | ---: | ---: | ---: |
| 良い効果 | 81 | 71 | 49 |
| 悪い効果 | 18 | 22 | 42 |
| 一斉事故 | 61 | 71 | 49 |

差引は出荷−展開費用。良い効果では即全社の81が、展開71と中止49を上回る。試験の1期間は他の2チームへ効果が乗らない。悪い効果では中止の42が、展開22と即全社18を上回る。害のある効果を広げない方が高い。一斉事故では展開の71が、即全社61と中止49を上回る。試験を経ると事故20を払わず、展開費用2で残りの期間を全社にできる。

固定3チームの仮説比較であり、本番の面白さや一般的優位の証明ではない。効果量、展開費用、事故の感度は次節。初回の3盤面表はそこでは再計算しない。

## 要因を一つずつ動かした比較

固定戦略の計算である。人間のプレイ評価はしていない。固定手順の差引を、本番の面白さやプレイヤーが境界を見て選べることの証明にはしない。本番採用の結論は出さない。

資源は初回と同じ。seed `RI-226`、チームは pilot、north、south、基礎出荷は各5、期間は3。差引は出荷−展開費用。即全社は3期間とも全社。展開は試験1期間のあと2期間全社。中止は試験のあと効果を外す。入力列は係数では変わらない。基準は良い効果が効果4・事故0、悪い効果が効果-3・事故0、一斉事故が効果4・事故20、展開費用2。動かした要因以外は変えない。盤面名は、効果と事故が初回のプリセットと一致する行ではその盤面、それ以外は列の基準盤面である。各行の数値は rules が正。数値は本番定数ではない。

展開と即全社の差は、事故−展開費用−2×効果。2×効果は、試験の1期間に north と south へ効果が乗らない分である。同点は優劣が無い。中止の差引も併記する。中止が最大のとき、展開が即全社を上回っても採る固定戦略は中止である。展開の手順は観測を見ずに全社へ進む。試験の観測差は効果だけで、事故は試験を飛ばした即全社だけが払い、観測には出ない。

効果だけを動かす。展開費用は2。事故0の列は良い効果と悪い効果の資源。事故20の列は一斉事故の資源で、列の中では事故を変えない。
