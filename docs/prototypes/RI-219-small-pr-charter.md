# RI-219: 小PR憲章で大きい出荷だけを禁止する

対象 #615 / 親 #548。結論: **限定比較の仮説採用、本番統合保留**。人間のプレイ評価は未実施。

## 固定盤面と憲章契約

通常ランから隔離した純TS試作。seed `RI-219` は盤面識別子で乱数は使わない。仕事は size 2・価値4のリスクなし1件と、size 4・価値10・リスク6の1件。期末は3。1期間に出荷か分割を1回。憲章の採用は tick 0 の一度だけで、期間は消費しない。採用後の変更は受け付けない。

憲章は size が2を超える出荷を拒否する。拒否は期間を消費しない。分割はその仕事を size 2・価値5・リスク0の2件に替え、1期間を使う。文化ボーナスや勝敗の宣言は持たない。既存のサイズ上限と併用する場合は小さい方だけを有効にし、効果は加算しない。上限が無いとき、憲章の上限は2。

安全な盤面のリスク重みは0。危険な盤面は1で、憲章なしに大きい仕事を出すとリスク6を引く。

差引は出荷価値から、憲章なしのときだけリスク×重みを引いた値。敗北状態は置かない。

安全な盤面では大きい仕事をそのまま出してから小さい仕事を終え、差引14。憲章は分割に1期間を使うため小さい仕事が残り、差引10。危険な盤面ではそのまま出すと10−6と小さい仕事4で差引8。憲章は分割後の10が上回る。原則を増やすだけでは有利にならない。
