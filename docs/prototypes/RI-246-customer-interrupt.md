# RI-246: 重要顧客の割り込みと計画済みの仕事を比べる

対象 #642 / 親 #548。結論: **限定比較の仮説採用、本番統合保留**。人間のプレイ評価は未実施。

## 固定イベント

通常ランから隔離した純TS試作。seed `RI-246` は盤面識別子で乱数は使わない。顧客契約や顧客層は作らず、見送りの代償は信頼6として示す。現行の urgent-demo のような即時出荷はしない。受注は割り込み仕事4を列へ足すだけで、その場の出荷は0である。

計画済みの仕事は6、1件の価値は5。完成すると完了ボーナス14を一度だけ足す。割り込みは4、1件の価値は3。1期間の処理は4。割り込みを受けた期間は、割り込みを先に処理してから計画へ回す。計画が終わったあとの余った期間は、処理0として進める。

盤面は処理期間の数だけが違う。余裕は3期間、逼迫は2期間である。見送りは信頼6を払い、計画だけを処理する。見送りは敗北にしない。

閲覧は、計画と割り込みの残量、1件の価値、完了ボーナス、処理量、期間数、見送りの信頼、両方の得点を選択前に示す。役立つ条件は処理3期間、不利な条件は処理2期間である。決定後の選択肢は空になる。

通常ランのイベント、顧客信頼、自動勝利、SPEC、保存、ruleset、固定トラック、WebGL停止契約へ接続しない。閲覧順で結果は変わらない。本番採用時は、追加した仕事と見送りの信頼を保存する別Issueに分割する。version 1の信頼済み内部JSONに比較の初期状態、入力列、得点の推移を含める。外部入力検証と通常保存互換は対象外。
