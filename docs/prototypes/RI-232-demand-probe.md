# RI-232: 観測できる確信度で、即出荷と試作品の期待値を比べる

対象 #628 / 親 #548。結論: **限定比較の仮説採用、本番統合保留**。優劣が反転する位置は要因比較に記録した。人間のプレイ評価は未実施。本番採用の結論は出さない。

## 固定盤面と試作品

通常ランから隔離した純TS試作。seed `RI-232` は盤面識別子で乱数は使わない。余力は4。反応する人数は RI-229 の固定ロスター4人で、期間中に増えない。需要候補は api と screen。噂は api。期間は3。試作品は1回だけで、報酬は2。完成品の報酬14は出荷の一度だけで、試作品では出ない。二度目の試作品と、一度でも出荷したあとの試作品は状態を変えない。正解でない出荷でも同じである。反応は、実際に試した候補への yes か no で、その候補が需要と一致するときだけ yes になる。同じ seed では変わらない。敗北状態にはしない。

閲覧は真の需要を出さない。操作前に示すのは、噂、完成報酬14、機会が消えるときの遅延報酬6、試作品報酬2、機会が消えるか、噂と別候補の重みである。重みは選択時の確信度であり、隠された需要そのものではない。

機会が消える観測では、最初の期間に14を取れなければ機会損失8を一度だけ記録する。遅れての正解は6になる。機会が残る観測では、遅れても出荷報酬は14である。噂を先に出荷する手順は、最初に api を出し、未完成なら次の期間に screen を出す。別候補を先に出す手順はその逆である。同じ候補を期末まで繰り返さない。試作品のあと出荷は、まず噂を試し、yes ならその候補、no ならもう一方を出荷する。

比較は、プレイヤーが見られる観測ごとに、噂が正しい世界と外れる世界を重み付きで合計する。個々の世界の順位を、見えない需要が分かっているものとして扱わない。

## 同条件比較

期待値は、噂が正しい世界の差引に噂の重みを掛け、外れる世界の差引に別候補の重みを掛けた合計である。行をまたいだ数値の大小は、重みの合計が違うため比べない。

| 観測 | 重み（噂:別） | 噂を先に出荷 | 試作品のあと | 別候補を先に出荷 |
| --- | ---: | ---: | ---: | ---: |
| 確信度が高く、機会が消える | 4:1 | 62 | 40 | 38 |
| 五分五分で、機会が消える | 1:1 | 20 | 16 | 20 |
| 五分五分で、機会が残る | 1:1 | 28 | 32 | 28 |

確信度が高く機会が消える観測では、噂を先に出荷する62が試作品のあと40と別候補先38を上回る。噂が外れた世界だけ遅延報酬6と機会損失8になり、重み付きの機会損失は8である。五分五分で機会が消える観測では、先にどちらかを出荷してから残りを出荷する20が、試作品のあと16を上回る。外れた世界の差引は6である。機会が残る観測では、試作品のあと32が先に両方へ出荷する28を上回る。遅延がないため二番目の正解も14で、試作品報酬2が上乗せされる。機会損失は0である。

固定3観測の仮説比較であり、本番の面白さや市場予測の証明ではない。重み、試作品報酬、遅延報酬の感度は次節。初回の3観測表はそこでは再計算しない。

## 要因を一つずつ動かした比較

固定戦略の計算である。人間のプレイ評価はしていない。固定手順の期待値を、本番の面白さや市場予測の証明にはしない。本番採用の結論は出さない。

資源は初回と同じ。seed `RI-232`、余力は4、反応する人数は4、期間は3、候補は api と screen、噂は api、完成報酬は14。期待値は、噂が正しい世界の差引に噂の重みを掛け、外れる世界の差引に別候補の重みを掛けた合計である。行をまたいだ数値の大小は、重みの合計が違うため比べない。入力列は係数では変わらない。噂を先に出荷は、最初に api を出し、未完成なら次に screen を出す。試作品のあとは、まず api を試し、yes なら api、no なら screen を出荷する。別候補を先に出す手順はその逆である。同じ候補を期末まで繰り返す三手目は、完成後の報酬を増やさない。基準は、確信度が高く機会が消える観測が重み4:1・試作品報酬2・遅延報酬6、五分五分で機会が消える観測が重み1:1・試作品報酬2・遅延報酬6、機会が残る観測が重み1:1・試作品報酬2・遅延報酬6で完成報酬のまま出荷する。動かした要因以外は変えない。観測名は、重みと機会の有無が初回のプリセットと一致する行ではその観測、それ以外は列の基準観測である。各行の数値は rules が正。数値は本番定数ではない。

比較する二者は、噂を先に出荷と試作品のあとである。同点は優劣が無い。別候補を先に出荷する期待値も併記する。別候補先が最大のとき、試作品が噂先を上回っても採る固定戦略は別候補先である。

機会が消えるとき、試作品の期待値から即出荷の期待値を引いた差は、噂の重み×(試作品報酬+遅延報酬−14)+別候補の重み×試作品報酬である。機会が残るとき、その差は(噂の重み+別候補の重み)×試作品報酬である。機会が残る観測では、遅延報酬を出荷に使わない。

噂の重みだけを動かす。別候補の重みは1、試作品報酬は2、遅延報酬は6。機会は消える。

`demand-probe-factor-comparison.json` に条件、規則、入力列、初期状態、期待値、機会損失、優劣、反転を残す。対象テストが再計算し、重み・試作品報酬・遅延報酬が初回の基準と一致する行が初回JSONの期待値と入力列と一致することを照合する。初回の比較JSONは更新していない。

次に解く不確実性: 反応は試した候補が需要と一致するときだけ yes になる。この一致を外すと、機会が消える観測で試作品報酬6と7、遅延報酬11と12のあいだにある即出荷から試作品への反転が残るかは未検証。

この要因比較は本番採用の判断を変えない。仮説は限定比較の採用のまま、本番統合は保留。

## 本番境界と検証

製品の販売、勝敗、画面更新による反応の引き直しへは接続しない。閲覧順で結果は変わらない。通常の編成、勝敗、SPEC、保存、ruleset、固定トラック、WebGL停止契約へ接続しない。本番採用時は試作品済みと出荷済みの保存、閲覧から真の需要を除く契約、完成報酬と機会損失の分離を別Issueに分割する。version 1の信頼済み内部JSONには再現のため真の需要を含める。外部入力検証と通常保存互換は対象外。

`demand-probe-comparison.json` に観測、重み、両世界の初期状態と入力列、期待値、機会損失を記録した。対象ユニット、毎入力のJSON保存再開と再生一致、型チェック、lint、format:checkを検証する。要因比較は Node 24 で対象ユニット、保存再開と入力再生、lint、format:check。UI/Pixiの変更はなく、E2Eとgalleryは対象外。通常ランの本番、UI、保存、rulesetへは接続していない。customSharedOrder と customerInterview は変更していない。
