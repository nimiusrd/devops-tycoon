# RI-190: 計画してから実装

対象 #586 / 親 #548。#585 / PR #778 の仕事盤面を使うstacked PR。結論: **限定比較の仮説採用、本番統合保留**。優劣が反転する位置は要因比較に記録した。人間のプレイ評価は未実施。本番採用の結論は出さない。

## 固定盤面と操作

通常ランから隔離した純TS試作。seed `RI-190` は盤面識別子（乱数なし）。RI-189の仕事盤面を人間速度（進捗1、利用費0）で進める。計画は2tickで、その間は対象仕事の進捗も出荷も増えない。計画の途中に実装tickを入れると無消費で拒否し、計画入力だけが残りを進める。1tickだけでは発見を返さない。2tick目に、複雑な仕事は `dependency:ledger-order`、単純な仕事は `no-hidden-scope` を記録する。計画が完了した仕事だけ作業量が6のままになる。

未計画の複雑な仕事は、最初の実装tickで作業量6が9になり、完了時に価値6を迷走ペナルティとして一度だけ引く。単純な仕事は未計画でも作業量も価値も変わらない。計画は未着手かつ未計画の先頭仕事だけを受け付ける。着手後、計画済み、別仕事の計画中、期末は無消費で拒否する。予算0のためRI-189の高速モデル割当も拒否される。閲覧では計画も実装も進まない。返す計画済み・発見・迷走の配列はコピーで、書き換えは元の状態に影響しない。

比較方針は公開情報だけを使う。`plan` は先頭の未計画仕事を2tick計画してから実装する。`rush` は計画せず実装する。

複雑な期末12では両方完了する。即着手は迷走ペナルティで12、計画は発見を残したまま18。計画の価値は「間に合うか」と「完了後の手戻り」の両方に出る。

## 要因を一つずつ動かした比較

資源は初回と同じ。seed `RI-190`、予算0、進捗1、作業量6、単純価値10、複雑価値18。盤面は単純・期末6、複雑・期末8、複雑・期末12。固定戦略は初回と同じで、`plan` は未計画のあいだ計画し、`rush` は実装だけを選ぶ。動かした要因以外は初回の係数（計画2tick、追加作業3、ペナルティ6）のまま。

固定戦略の計算である。人間のプレイ評価はしていない。途中で方針を変えるプレイヤーの証拠にはしない。本番採用の結論は出さない。初回の三行は各表の対照であり、この節の新しい結論にしない。

順位は出荷価値だけで決める。計画が高ければ計画、即着手が高ければ即着手、同じなら同点。差は計画の出荷から即着手の出荷を引いた値。発見と迷走の記録は順位に使わない。括弧内は即着手の出荷対計画の出荷。

迷走量は試作では二つの数なので、追加作業と完了時ペナルティを別々に動かす。一つの倍率には合成しない。発見は、指定した計画tickに達したtickで一度記録する。初回の2tickでは1tick目に発見はない。計画tickを1にすると、その1tickで発見が残る。

## 本番境界と検証
