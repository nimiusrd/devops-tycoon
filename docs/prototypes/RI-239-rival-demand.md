# RI-239: 追随と独自路線を同じ余力で比べる

対象 #635 / 親 #548。結論: **限定比較の仮説採用、本番統合保留**。人間のプレイ評価は未実施。

## 固定予告

通常ランから隔離した純TS試作。seed `RI-239` は盤面識別子で乱数は使わない。リアルタイムの競合AIは置かない。競合は機能 match を期間1の開始時に公開する、と期間0から予告されている。影響する顧客は RI-229 の pioneer で、人数は4。自社の作業順を見ても、公開時刻と価格表は変わらない。

自社の候補は match と own。必要作業は各4、余力は4、期間は2。1期間に1機能が完成し、価値はその時点の価格を一度だけ足す。完成済みへ作業しても価値は増えない。RI-228 の完成判定を使い、余った作業はもう一方へ移さない。敗北状態にはしない。

公開前の価格は match 8、own 8。公開後は盤面で固定する。

| 盤面 | 公開後の match | 公開後の own |
| --- | ---: | ---: |
| 先回り | 3 | 10 |
| 裏付け | 14 | 6 |

追随は match を先に完成させる。独自路線は own を先に完成させる。資源は同じである。

閲覧は予告の機能、公開時点、顧客層と人数、公開前と公開後の価格、今の価格、残り作業を示す。閲覧では期間も価格表も動かない。

## 同条件比較

成果は、完成時点の価格を足した値である。

| 盤面 | 追随 | 独自路線 |
| --- | ---: | ---: |
| 先回り | 18（8、その後10） | 11（8、その後3） |
| 裏付け | 14（8、その後6） | 22（8、その後14） |

先回りでは、公開前に match を出す追随が、公開後に値下がりした match を受ける独自路線を上回る。裏付けでは、公開後に上がった match を取る独自路線が、公開前の8で match を確定した追随を上回る。競合と逆の own から始める戦略は先回りで不利になる。同じ価格表を、追随でも独自路線でも使う。

固定2盤面の仮説比較であり、本番の市場の証明ではない。次は公開時刻と価格差の感度を見る。
