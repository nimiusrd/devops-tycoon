# RI-251: 失敗したボスの宿題と新しい目標を比べる

対象 #647 / 親 #548。結論: **限定比較の仮説採用、本番統合保留**。人間のプレイ評価は未実施。

## 固定イベント

通常ランから隔離した純TS試作。seed `RI-251` は盤面識別子で乱数は使わない。前期の監査で証拠が4不足した継続可能な未達だけを、理由 `evidence-short` として次期へ1件持ち越す。ランが終了する敗北は持ち越さず、この試作は自動継続しない。

宿題は証拠4を終えると一度だけ解消する。同じ未達から宿題を重ねない。未解消の期間はペナルティを1回足し、解消した期間からは足さない。新しい目標は作業4、価値14で、受付期間を過ぎると取り逃す。1期間の処理は4。宿題を優先するとその期間は目標へ回らない。未対応の残リスクは、残証拠×期間ペナルティとして得点とは別に残し、開始直後の敗北にはしない。

盤面は目標の受付期間とペナルティだけが違う。持続は作業3期間、受付3期間、未解消ペナルティ5。露出は作業1期間、受付1期間、未解消ペナルティ3。閲覧は、未達理由、残証拠、解消条件、受付期間、ペナルティ、両方の得点と残リスクを選択前に示す。決定後の選択肢は空になる。

## 同条件比較

得点は、目標の価値から支払ったペナルティを引いた値である。残リスクは得点に含めない。

| 盤面 | 宿題優先 | 新目標優先 |
| --- | ---: | ---: |
| 目標が3期間残る | 14 | 9 |
| 目標が今期だけ | 0 | 11 |

目標が残る盤面では、先に証拠を終えてから目標14を取り、ペナルティ0で14になる。目標を先に取ると未解消の1期間で5を引き、9になる。どちらの順でも宿題は1件のまま解消する。目標が今期だけの盤面では、宿題を先にすると目標を取り逃して0、目標を先にすると14からペナルティ3を引いた11になり、証拠4と残リスク12が残る。残っていても敗北にしない。宿題優先が常に上位ではない。

固定2盤面の仮説比較であり、本番のボス継続の証明ではない。残リスクを得点へ入れた比較は次節で、この2盤面の再計算ではない。

## 残リスクを得点へ入れた比較

採否は変えない。限定比較の仮説は採用のまま、本番統合は保留のまま。本番採用の結論は出さない。人間のプレイ評価はしていない。固定戦略の計算であり、途中で方針を変える適応や、面白さの証拠ではない。初回の2盤面の表は再計算しない。

資源は初回の今期限りの盤面と同じ。seed `RI-251`、処理4、宿題の証拠4、目標の作業4・価値14、受付1期間、未解消の期間ペナルティ3、作業1期間。方針は最初に宿題か目標かを決め、その後は作業するだけ。選択前の閲覧は初回と同じく、残リスクを得点の外に置く。

ここでの得点は、目標の価値から支払ったペナルティと、未解消の宿題に付けた残リスクを引いた値である。宿題を終えた側の残リスクは0。目標を先に取った側は、初回と同じく価値14からペナルティ3を引いた11が土台で、そこから残リスクをさらに引く。動かすのはその残リスクだけ。指定した残リスクは証拠4が残ったときの減点で、実際の減点は残証拠×指定残リスク÷4。初回の残リスクは残証拠4×期間ペナルティ3で12。12を挟む前後として8から16までを付ける。負の得点でも敗北にはしない。

目標が3期間残る盤面は、どちらの順でも宿題を解消するので残リスクは0のままである。初回の14と9はここでは動かさない。

| 残リスク | 宿題 | 今期目標 | 優劣 |
| ---: | ---: | ---: | --- |
| 8 | 0 | 3 | 今期目標 |
| 9 | 0 | 2 | 今期目標 |
| 10 | 0 | 1 | 今期目標 |
| 11 | 0 | 0 | 同点 |
| 12 | 0 | -1 | 宿題 |
| 13 | 0 | -2 | 宿題 |
| 14 | 0 | -3 | 宿題 |
| 15 | 0 | -4 | 宿題 |
| 16 | 0 | -5 | 宿題 |

残リスク10までは今期目標が上、11は同点、12以上は宿題が上になる。初回の残リスク12では宿題が上回る。同点から宿題が上になる境界は11と12のあいだ。今期目標が上に戻る境界は残リスク10以下。

条件、入力列、土台の得点、残リスクを入れた得点は `boss-homework-residual-comparison.json` にあり、テストが同じ関数の再計算と照合する。この比較も本番のボス継続の証明ではない。

次に解く不確実性: 未解消の宿題が次の期間も期間ペナルティを足し続けるとき、作業1期間の期末に残リスクを一度引いただけの「12以上で宿題が上回る」境界が残るかは未検証。
