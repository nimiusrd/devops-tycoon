# RI-243: 四半期内の返済記録と出荷全力を比べる

対象 #639 / 親 #548。結論: **限定比較の仮説採用、本番統合保留**。人間のプレイ評価は未実施。

## 固定イベント

通常ランから隔離した純TS試作。seed `RI-243` は盤面識別子で乱数は使わない。勝敗や信頼の自動判定は変えない。交渉を見送っても敗北にはしない。

仕事は2枠。出荷は納品4。返済は納品1と、負債3の減少、四半期の記録3である。返済は残債が3以上のときだけでき、記録はその枠の時点で残す。開始時の負債残高は記録ではない。負債0も、過去の改善としては扱わない。

交渉は2枠のあとで、記録の合計が3以上のときだけ出る。受けると次期目標を4下げ、信頼を2払う。記録が足りない交渉は拒否する。目標の緩和は次期の不足を減らすだけで、今期の納品は増えない。

次期の処理能力は8。不足1につき得点を3引く。得点は、納品から信頼と不足ペナルティを引いた値である。

盤面は3つ。余裕は次期目標8、逼迫と見かけの健全は次期目標14。余裕と逼迫の開始負債は6。見かけの健全は開始負債0で、返済記録を作れない。

閲覧は負債、記録、交渉の可否、理由、提示する緩和と信頼、両方の見通しを示す。記録が無い理由は、負債が残っているときは四半期の記録不足、負債0のときは現在値を記録にしないことである。

## 同条件比較

| 盤面 | 出荷全力 | 返済して交渉 | 記録 |
| --- | ---: | ---: | --- |
| 次期目標8 | 8 | 3 | 交渉側だけ3 |
| 次期目標14 | -10 | -3 | 交渉側だけ3 |
| 負債0で目標14 | -10 | -10 | どちらも0 |

余裕では次期の不足が初めから無く、出荷8が、納品5と信頼2の交渉3を上回る。逼迫では出荷の不足6で得点-10、返済で目標が14から10になり得点-3が上回る。交渉は常に上位ではない。負債0では返済を見送った記録が残り、交渉は出ない。得点は出荷と同じ-10である。

固定3盤面の仮説比較であり、本番の目標修正の証明ではない。次は信頼2と緩和4の感度を見る。

## 本番境界と検証

通常ランの目標修正、信頼、自動勝利、SPEC、保存、ruleset、固定トラック、WebGL停止契約へ接続しない。閲覧順で結果は変わらない。本番採用時は、四半期内の返済記録と交渉の受諾を保存する別Issueに分割する。version 1の信頼済み内部JSONに比較の初期状態、入力列、得点の推移を含める。外部入力検証と通常保存互換は対象外。

`negotiation-record-comparison.json` に盤面、初期状態と入力列、得点の推移を記録した。対象ユニット、毎入力のJSON保存再開と再生一致、型チェック、lint、format:checkを検証する。UI/Pixiの変更はなく、E2Eとgalleryは対象外。
