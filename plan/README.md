# plan/ ドキュメント索引

DevOps Tycoon の計画・設計ドキュメント一式の置き場で、このファイルがその索引。段階的な実装は一通り完了したため、本ディレクトリは現状の実装と SPEC の対応・残務・設計判断を追うための資料に位置づける。

> 方針: SPEC 第22章「技術構成」をアーキテクチャの前提とする。**シミュレーション層を描画から分離し、seed付き決定論で実装する**ことを横断規律とする（第22.3〜22.5）。SPEC 各章とコードの対応・充足状況は [spec-mapping.md](./spec-mapping.md) を参照。

---

## 現状

- 実装は一通り完了し、`src/`（sim / state / render / ui）と `tests/`（Vitest / Playwright E2E）が揃って `npm run dev` で通しプレイできる。
- 盤面描画は既定で PixiJS（WebGL。全社マップ・部署ビュー・現場盤面）、`?renderer=dom` で DOM/SVG へ opt-out。WebGL 不可環境は自動フォールバック（RI-11）。
- SPEC 各章の充足状況（✅/🟡）と残務の追跡先は [spec-mapping.md](./spec-mapping.md) §1・§2 に集約。見た目の確認は `npm run gallery`（画面ギャラリー一括撮影）と Playwright 視覚回帰で行う（第22.2/22.5。旧 `mockups/` は廃止済み）。
- 残務・未解決事項は [remaining-issues.md](./remaining-issues.md) に一本化して追跡する。

## リスクと留意点

- **世界観の制約（第2.1章）**: イベント/ボス/敗北/称号/演出は「現実の開発組織で起こりうる範囲」に留める（[architecture.md](./architecture.md) §4.5）。
- **バランス調整コスト**: 確率モデルのチューニングは Web Worker のモンテカルロ試算（第22.3）＋データ駆動定義で回す。
- **状態の複雑化**: ゲーム内のフェーズ遷移は純TS遷移表（`src/sim/run/phases.ts`。XState マシンはそこから生成）、ラン/メタ状態は Zustand に分離して肥大化を防ぐ。

## 残務の進め方

主な残務はバランス調整（四半期レビューの代償・outcome 閾値ほか）と横断的な繰り越し（統計テスト基盤・レバーバランス・業界とメタ進行の接続・メタ解放対象の拡張など）。詳細と追跡先は [remaining-issues.md](./remaining-issues.md) と [spec-mapping.md](./spec-mapping.md) §2 を参照。

プレイテスト所感（2026-07）「視覚的な面白さに欠ける・選択のリスク・リターンがわかりにくい」を受けて、**選択の可視化・フィードバック（UX）グループ（RI-43〜48）**を新設した。選択肢への効果プレビュー（事前）とステータス増減の演出（事後）を対で整備する方針。盤面の動きに直結する RI-05 / RI-06 も高優先へ格上げ済み。

続くプレイテスト所感（2026-07 第2回）「操作に対するフィードバックが弱く、何が良い手かわからずプレイ改善ができない」を受けて、**介入フィードバックループのグループ（RI-49〜55＋RI-56）**を追加した。①即時（介入結果ペイロード・盤面リアクション・失敗理由）→ ②スプリント内（イベントティッカー・タイムライン）→ ③リザルト（介入効果分析・無介入ベースライン比較）の 3 層でループを閉じ、効果量の数値担保（RI-56）を対にする。詳細は [remaining-issues.md](./remaining-issues.md) の UX グループ導入文を参照。

2026-07-18 の棚卸しで RI-01〜RI-57 の主要残務は完了し、通しテスト DoD（RI-40: unit 771 件・E2E 40 件・lint / format / build）も緑を確認した。RI-28（コア接続 + ′内訳可視化 + ″解放ゲート）は完了し、RI-34′／RI-34″（なぜ燃えたか・AI導入失敗図鑑）も完了。RI-58（ラン途中セーブ）・RI-59（サウンド）・RI-60（オンボーディング）・RI-61（リプレイ）・RI-62（テンポ）も完了。外部 API 拡張は仕様から削除済み。残るのは保留(要判断)の RI-34（ローカル拡張の残り）など。詳細は [remaining-issues.md](./remaining-issues.md) を参照。

さらにプレイテスト所感（2026-07 第3回）「ゲームスピードが速すぎて介入する前にスプリントが終わる」を受けて、**RI-62（ゲームスピードの調整）を優先度:高で追加**した。実測でスプリントは実時間 2.2〜12.2 秒（中央値 約6秒）で完了しており、RI-49〜55 の介入フィードバックループ以前に介入の時間的余地がない。既定テンポの減速＋速度コントロール UI を主案とする（詳細は RI-62 の項）。
