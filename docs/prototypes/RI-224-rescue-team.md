# RI-224: 救援1期間の集中派遣と分散派遣を比べる

対象 #620 / 親 #548。結論: **限定比較の仮説採用、本番統合保留**。人間のプレイ評価は未実施。

## 固定盤面と貸し出し契約

通常ランから隔離した純TS試作。seed `RI-224` は盤面識別子で乱数は使わない。チームは alpha、bravo、spare の3つ。各余力は4。救援期間は1。貸し出した余力は元チームの出荷に使わず、救援プールだけで復旧する。終了も中断も、貸し出しを一度だけ0へ戻す。二度目の返却は状態を変えない。中断は復旧前に戻すため、復旧は0のまま未解決の罰を確定する。返却後の1期間は全員が元の余力で出荷する。敗北状態にはしない。

見送りは貸し出さない。集中は出荷単価が最も低いチームから、障害量か余力4の小さい方を出す。同単価は spare を選ぶ。分散は各チームが障害量÷3の切り上げを出し、余力4を超えない。

収まる障害は障害4、未解決1につき5、単価は全員2。広い障害は障害6、未解決1につき6、単価は全員2。納期は障害4、未解決1につき3、alpha の単価6、bravo と spare は2。

## 同条件比較

| 盤面 | 見送り | 集中 | 分散 |
| --- | ---: | ---: | ---: |
| 収まる障害 | 28 | 40 | 36 |
| 広い障害 | 12 | 28 | 36 |
| 納期 | 68 | 72 | 60 |

差引は出荷−未解決の罰。収まる障害では集中の40が、分散36と見送り28を上回る。1チームで足りるのに分散は各2、合計6を出して出荷を余分に落とす。広い障害では分散の36が、集中28と見送り12を上回る。1チームの余力4では障害6が残る。納期では集中の72が、見送り68と分散60を上回る。均等に出すと単価6の alpha を削り、何もしないより差引が低い。

固定3チームの仮説比較であり、本番の面白さや一般的優位の証明ではない。次は救援期間、余力、未解決罰の感度を見る。
