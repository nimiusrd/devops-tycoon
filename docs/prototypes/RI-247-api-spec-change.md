# RI-247: 利用APIの仕様変更に追従・代替・停止で対応する

対象 #643 / 親 #548。結論: **限定比較の仮説採用、本番統合保留**。人間のプレイ評価は未実施。

## 固定イベント

通常ランから隔離した純TS試作。seed `RI-247` は盤面識別子で乱数は使わない。外部APIやネットワークは作らず、架空の課金API1種が `billing` だけに修正仕事を出す。関係ない仕事は `other` で、1件の価値は4のまま減点しない。

機能を期限内に戻すと出荷価値16を一度だけ足す。追従の残リスクは、狭い依存で2、広い依存で14。代替の残リスクは0。期限までに終わらない追従と代替は、機能価値を足さず未解消リスク8を一度だけ残す。停止は修正作業0で機能価値を捨て、残リスクは0。1期間の処理は4。対応作業を先に進め、余った処理だけを関係ない仕事へ回す。

盤面は残り期間と依存の広さだけが違う。狭い長期は追従4・代替8・処理3期間。広い長期は追従8・代替12・処理4期間。広い短期は追従8・代替12・処理2期間。停止は敗北にしない。

閲覧は、影響領域、期限、追従と代替の作業量、機能価値、残リスク、関係ない仕事の件数と単価、3対応の得点を選択前に示す。決定後の選択肢は空になる。

## 同条件比較

得点は、処理した関係ない仕事と機能価値から残リスクを引いた値である。

| 盤面 | 追従 | 代替 | 停止 |
| --- | ---: | ---: | ---: |
| 狭い・処理3期間 | 38 | 32 | 24 |
| 広い・処理4期間 | 26 | 32 | 24 |
| 広い・処理2期間 | 2 | -8 | 24 |

狭い長期では追従が機能16を残し、関係ない仕事6を終えて38になる。代替は機能を残すが関係ない仕事が4件で32。広い長期では追従の残リスク14が効き、代替32が追従26を上回る。広い短期では追従も代替も関係ない仕事に手が回らず、停止が関係ない仕事だけを終えて24になる。未完の代替は機能0と未解消8で-8。停止が常に上位ではない。

## 本番境界と検証

通常ランのイベント、タスク属性、自動勝利、SPEC、保存、ruleset、固定トラック、WebGL停止契約へ接続しない。閲覧順で結果は変わらない。本番採用時は、影響領域と対応作業と停止した機能価値を保存する別Issueに分割する。version 1の信頼済み内部JSONに比較の初期状態、入力列、得点の推移を含める。外部入力検証と通常保存互換は対象外。

`api-spec-change-comparison.json` に盤面、初期状態と入力列、得点の推移を記録した。対象ユニット、毎入力のJSON保存再開と再生一致、型チェック、lint、format:checkを検証する。UI/Pixiの変更はなく、E2Eとgalleryは対象外。
