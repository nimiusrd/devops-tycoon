# Codex 再レビュー依頼

1. 初回以降の修正後に `@codex review` を投稿する
2. 対応済みの指摘には返信し、スレッドを解決済みにする
3. マージせず merge-ready で止める

`@codex review` の投稿とスレッドへの返信は、いずれも **コメント者がユーザー本人** になるようにする。ボットやエージェント名義（例: `cursor`）では投稿しない。

## 1. 初回以降だけ `@codex review` を投稿する

PR 作成時の初回 Codex レビューは自動で走る。改めて依頼するのは、**初回以降に指摘へ対応して push したあと**だけである。

そのとき PR コメントとして、次の一文だけを投稿する。

```text
@codex review
```

- 余分な文言・チェックリスト・署名を付けない
- PR 作成直後や、まだ一度も指摘対応していない段階では投稿しない
- 同じ HEAD に対して連投しない。新しい push のあとなら再投稿してよい
- Draft の Ready 化はユーザーが明示したときだけ行う

## 2. 対応済み指摘は返信して resolve する

指摘へ対応したら（修正でも dismiss でも）、そのスレッドに返信し、解決済みにする。
返信もコメント者はユーザー本人とする。

## 3. ループの止め方

未解決の Codex 指摘が無く、CI も問題なければ merge-ready として報告して止める。
**ユーザーが明示しない限りマージしない。**
