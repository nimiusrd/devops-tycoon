# RI-232: 機会が消える需要と外れ候補で、即出荷と試作品を比べる

対象 #628 / 親 #548。結論: **限定比較の仮説採用、本番統合保留**。人間のプレイ評価は未実施。

## 固定盤面と試作品

通常ランから隔離した純TS試作。seed `RI-232` は盤面識別子で乱数は使わない。余力は4。反応する人数は RI-229 の固定ロスター4人で、期間中に増えない。需要候補は api と screen。噂は api。期間は3。試作品は1回だけで、報酬は2。完成品の報酬14は出荷の一度だけで、試作品では出ない。二度目の試作品は状態を変えない。反応は盤面で決まり、同じ seed では変わらない。敗北状態にはしない。

閲覧は真の需要を出さない。試作品の前は噂と報酬の差だけを示す。反応は、試した候補への yes か no だけで、もう一方の名前は返さない。

機会が消える盤面の真の需要は api。最初の期間に出荷すると14、遅れると6。外れ候補の盤面の真の需要は screen で、遅れても14のまま。即出荷は噂の api を作る。試作品は api を確認し、yes なら api、no なら screen を出荷する。別候補は最初から screen を出荷する。

## 同条件比較

差引は試作品の報酬と出荷の報酬の合計。失った機会は別列。

| 盤面 | 即出荷 | 試作品のあと出荷 | 別候補を即出荷 |
| --- | ---: | ---: | ---: |
| 機会が消える | 14 | 8 | 0 |
| 外れ候補 | 0 | 16 | 14 |

機会が消える盤面では即出荷の14が、試作品のあと8と別候補0を上回る。試作品は需要が api だと分かるが、出荷報酬は14から6になり、機会の損失は8。試作品自体の報酬2を足しても8。外れ候補の盤面では試作品のあと16が、別候補14と即出荷0を上回る。即出荷は噂の api を完成させても報酬がない。別候補は当たるが、試作品の報酬2がない。

固定2候補の仮説比較であり、本番の面白さや市場予測の証明ではない。次は試作品報酬、遅れた出荷報酬、候補数の感度を見る。

## 本番境界と検証

製品の販売、勝敗、画面更新による反応の引き直しへは接続しない。閲覧順で結果は変わらない。通常の編成、勝敗、SPEC、保存、ruleset、固定トラック、WebGL停止契約へ接続しない。本番採用時は試作品済みの保存、閲覧から真の需要を除く契約、完成報酬と機会損失の分離を別Issueに分割する。version 1の信頼済み内部JSONには再現のため真の需要を含める。外部入力検証と通常保存互換は対象外。

`demand-probe-comparison.json` に初期状態、入力列、試作品報酬、機会損失、差引を記録した。対象ユニット、毎入力のJSON保存再開と再生一致、型チェック、lint、format:checkを検証する。UI/Pixiの変更はなく、E2Eとgalleryは対象外。
