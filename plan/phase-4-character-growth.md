## 目的

開発者・シニアを**個体**として扱い、育成と編成の対象にする。採用カードを単なる数値ではなく「未来の主力をどう育てるか」の選択にする。

## タスク

- メンバー個体（実装力 / レビュー力 / AI習熟 / スタミナ）とトレイト（AI職人 / 巨大PR製造機 / レビュー鬼 / ドキュメント魔 / ジュニアの星 / 燃え尽き気味 等）
- 成長: タスク経験でレベルアップ、ジュニア → ミドル → シニア昇格
- 編成: どのレーンに誰を置くか、AIを誰に配るか（戦術化）
- スタミナ管理と離脱（休職）リスク
- 表情演出（疲れ顔 / ガッツポーズ等）をビジュアルに反映

## 成果物

採用カードが「未来の主力育成」の選択になり、編成が結果に影響する。

## テスト

- Vitest: 成長 / 昇格 / スタミナ閾値、編成が結果に与える影響、トレイト効果
- Playwright: 編成 UI 操作のスモーク

## 完了の目安（DoD）

個体育成・編成が戦術として機能する。
