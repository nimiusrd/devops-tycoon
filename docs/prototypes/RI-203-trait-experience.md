# RI-203: 経験で変わるトレイト

対象 #599 / 親 #548。結論: **限定比較の仮説採用、本番統合保留**。人間のプレイ評価は未実施。

## 固定盤面と情報

通常ランから隔離した純TS試作。seed `RI-203` は盤面識別子で乱数は使わない。人物IDは `ren` で固定する。最初のトレイトIDは現行データの `megaPrMaker`。表示名ではなくIDと効果で追う。この試作の効果は整数の代替で、本番の `implMul` 1.25 と `reviewLoadMul` 0.9 そのものではない。巨大PRの出荷は価値6・レビュー負荷4。

経験は分割1回につき1。必要な回数は2で、閲覧に最初から出す。出荷やtickの経過だけでは経験は増えない。2回目の分割で `megaPrMaker` が消え、後継ID `prSplitter` が一度だけ付く。後継の出荷は価値4・負荷1。付与回数は1で、その後に分割してもIDは増えない。最初から `prSplitter` だけの人物は、分割しても重複して付かない。両方持っている場合は旧IDだけ外れ、後継は足さない。両方あるあいだの効果は後継を優先する。

急ぐ盤面は期末3、負荷の重み1。混雑盤面は期末6、負荷の重み2。差引は出荷価値−負荷×重み。方針は毎tick出荷するか、必要回数まで分割してから出荷するか。

## 同条件比較

| 盤面 | 出荷を続ける | 2回分割してから出荷 |
| --- | ---: | ---: |
| 急ぐ | 6 | 3 |
| レビュー混雑 | -12 | 8 |

急ぐ盤面では3回とも巨大PRを出す差引6が、分割2回と後継の出荷1回の3を上回る。トレイトは `megaPrMaker` のまま。混雑盤面では負荷が2倍に効く。出荷継続は価値36でも負荷24で差引-12。分割経験のあと後継を4回出すと価値16・負荷4で差引8。同じ人物でも、今の出荷を取るか負荷を先に下げるかで有力な手が変わる。差引が負でも敗北状態にはしない。

固定係数の仮説比較であり、本番の面白さや一般的優位の証明ではない。次は必要回数、後継の価値、負荷の重みの感度を見る。

## 本番境界と検証

#537は既存成長の表示。本件は経験回数によるトレイト遷移の試作で、`TRAIT_DEFS` やメタ解放は増やさない。後継ID `prSplitter` は本番のトレイト一覧に入れない。RI-166のPR分割モデルとは未接続。通常の編成、勝敗、SPEC、保存、ruleset、固定トラック、WebGL停止契約へ接続しない。本番採用時は対象トレイト、必要回数、表示と保存を別Issueに分割する。version 1の信頼済み内部JSONのみ。外部入力検証と通常保存互換は対象外。

`trait-experience-comparison.json` に初期状態、入力列、人物ID、トレイトID、付与回数、効果、結果を記録した。対象ユニット、毎入力のJSON保存再開と再生一致、型チェック、lint、format:checkを検証する。UI/Pixiの変更はなく、E2Eとgalleryは対象外。
