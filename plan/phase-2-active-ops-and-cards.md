## 目的

「眺める」から「捌く」へ。介入アクション・集中力・コンボ・カードドラフトを追加し、同じデッキでも捌き方次第で結果が変わるようにする。

## タスク

### 能動操作（第6章）

- マネジメント集中力 ⚡（毎スプリント回復、スプリント中は回復しない）
- 介入アクション: 割り込みレビュー / PR分割 / 緊急対応🔥 / タスク差配 / AIスロットル / 残業号令 / アンドン⏸ / ペアモブレビュー（第6.1の表＝コスト・CD・副作用）
- 介入アクションバー UI（⚡コスト・CD・Ready 表示 / 第4.3章）
- リアルタイム演出メーター: 渋滞メーター・炎上タイマー（第6.3章）
- コンボと連携ゲージ（第6.2章）

### カード / デッキ（第7章）

- データ駆動のカード定義（第7.2章の例を `src/data/cards`）、レアリティ（コモン/レア/レジェンダリ）
- スプリント後のドラフト（3枚→1枚）、手札配布、発動
- カード強化（コスト減/効果増）の枠組み（ショップ/休息ノードは [phase-3](./phase-3-roguelike-loop.md) で接続）

### 演出（第18.2章）

- 数字ポップ、`COMBO xN`、渋滞ヒートマップ、延焼/鎮火、スイープ（Framer Motion + DOM/SVG）

## 成果物

スプリント中に介入して結果が変わる。ドラフトでデッキが育つ。

## テスト

- Vitest: 集中力消費 / CD / 副作用、コンボ倍率、カード効果の状態反映
- Playwright: 介入アクション発動 → 渋滞が捌ける操作 E2E（第22.5）

## 完了の目安（DoD）

介入 / 集中力 / コンボ / ドラフトで結果が変わることを操作 E2E で確認。
