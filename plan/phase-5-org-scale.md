## 目的

1チームの現場から、複数チーム・複数部署を抱える巨大組織へスケールさせる。同じアイソメトリックの作法のまま、現場↔部署↔全社↔業界を地続きにズームできるようにする。

## タスク

- **ズーム階層（第4.7章）**: 業界 ▸ 全社 ▸ 部署 ▸ 現場 とパンくず移動。下位の事象を上位に集約、上位レバーで下位制約を緩める設計。
- **全社マップ（第4.8章 / `mockups/org-screen`）**: 部門ゾーン・チーム島・共通基盤ハブ・チーム間フロー・全社レバー（採用ドラフト / 全社AIガイドライン / 基盤投資 / 標準化 / 火消し部隊 / 組織再編）
- **部署ビュー（第4.9章 / `mockups/dept-screen`）**: チーム＝小パイプライン（Coding▸Review▸Done）、チーム間依存の連鎖炎上、部門レバー
- **業界ランキング（第4.10章 / `mockups/industry-screen`）**: シーズン制リーダーボード・リーグ・ベンチマーク・ランキング種別タブ・HQスカイライン
- **ドリルダウン / ズームアウト（第4.11章 / `mockups/drilldown`）**: pixi-viewport によるカメラ寄り＋クロスフェード。遷移先の状態（炎上・渋滞）を遷移演出にも反映。

## 描画前提

PixiJS + pixi-viewport を本格採用。数百〜数千の動的オブジェクトはスプライトで扱い、depth sort / 画面外カリング / ズームを viewport とソートで処理（第22.2）。

## 成果物

現場↔部署↔全社↔業界を地続きにズームして采配できる。

## テスト

- Vitest: アイソメ投影 / depth sort / カリング、状態→見た目、カリング数 / プール再利用 / 生成スプライト数の上限を数値検証（第22.5）
- Playwright: 視覚回帰（seed＋一時停止で固定フレーム）、ドリルダウン操作 E2E

## 完了の目安（DoD）

4階層ズーム・全社 / 部署 / 業界ビュー・カメラ遷移が動作する。
