# RI-220: 小PR憲章を1期間だけ破る

対象 #616 / 親 #548。結論: **限定比較の仮説採用、本番統合保留**。人間のプレイ評価は未実施。

## 固定盤面と例外契約

通常ランから隔離した純TS試作。禁止判定は RI-219 の `charterBlocks` を使う。seed `RI-220` は盤面識別子で乱数は使わない。憲章は最初から有効で、上限は2。緊急の仕事は size 4 で、tick 0 に例外で出さないと期限切れになる。例外はその1期間のその1件だけで、二度目の例外と、その後の size 4 の出荷は拒否する。拒否は期間を消費しない。

通常出荷は1期間に価値3。例外を使った場合だけ、tick 3 の後日談で信頼費用を一度引く。費用は `followUpApplied` で再適用しない。閲覧は状態を変えず、集計を繰り返しても費用は増えない。

納期盤面は緊急価値12、後日談4。先例盤面は緊急価値6、後日談8。期末はどちらも4。

## 同条件比較

| 盤面 | 憲章を維持 | 1件だけ例外 |
| --- | ---: | ---: |
| 納期 | 12 | 17 |
| 先例 | 12 | 7 |

差引は出荷価値−後日談の信頼費用。維持は緊急を期限切れにし、通常出荷3を4期間積んで12。信頼費用は0。例外は緊急価値に通常出荷3期間を足し、後日談を一度引く。納期では21−4=17が維持の12を上回る。先例では15−8=7が維持の12を下回る。どちらにも成果と代償がある。全待ちは差引0で敗北にしない。

固定係数の仮説比較であり、本番の面白さや一般的優位の証明ではない。次は例外の持続、後日談の発生tick、緊急価値の感度を見る。

## 本番境界と検証

RI-240 の後日談イベントとは未接続。人格的な罰は置かず、後の信頼費用だけを引く。通常の編成、勝敗、SPEC、保存、ruleset、固定トラック、WebGL停止契約へ接続しない。本番採用時は例外履歴の保存、憲章への復帰、後日談の一度だけの反映を別Issueに分割する。version 1の信頼済み内部JSONのみ。外部入力検証と通常保存互換は対象外。

`charter-exception-comparison.json` に初期状態、入力列、例外tick、後日談、信頼費用、差引を記録した。対象ユニット、毎入力のJSON保存再開と再生一致、型チェック、lint、format:checkを検証する。UI/Pixiの変更はなく、E2Eとgalleryは対象外。
