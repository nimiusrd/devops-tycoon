# RI-232: 機会の消失と需要の当たり外れで、即出荷と試作品を比べる

対象 #628 / 親 #548。結論: **限定比較の仮説採用、本番統合保留**。人間のプレイ評価は未実施。

## 固定盤面と試作品

通常ランから隔離した純TS試作。seed `RI-232` は盤面識別子で乱数は使わない。余力は4。反応する人数は RI-229 の固定ロスター4人で、期間中に増えない。需要候補は api と screen。噂は api。期間は3。試作品は1回だけで、報酬は2。完成品の報酬14は出荷の一度だけで、試作品では出ない。二度目の試作品と、完成品を出荷したあとの試作品は状態を変えない。反応は盤面で決まり、同じ seed では変わらない。敗北状態にはしない。

閲覧は真の需要を出さない。試作品の前は噂、完成報酬14、遅れた出荷報酬6、試作品報酬2、機会が消えるかを示す。機会の消失と需要は別々に組み合わせる。消失が api を意味することはない。反応は、試した候補への yes か no だけで、もう一方の名前は返さない。

消失する盤面は、最初の期間に14を取れなければ機会損失8を一度だけ記録する。正解を後から出荷しなくても、その期間を離れた時点で記録する。遅れた正解の出荷報酬は6。消失しない盤面の出荷報酬は、期間が遅れても14。即出荷は噂の api を作る。試作品は api を確認し、yes なら api、no なら screen を出荷する。別候補は最初から screen を出荷する。

## 同条件比較

差引は試作品の報酬と出荷の報酬の合計。失った機会は別列で、差引からは二重に引かない。

| 盤面 | 即出荷 | 試作品のあと出荷 | 別候補を即出荷 |
| --- | ---: | ---: | ---: |
| 消失し、噂が正しい | 14 | 8 | 0 |
| 消失し、噂が外れる | 0 | 8 | 14 |
| 消失せず、噂が正しい | 14 | 16 | 0 |
| 消失せず、噂が外れる | 0 | 16 | 14 |

噂が正しく機会が消える盤面では、即出荷の14が試作品のあと8と別候補0を上回る。試作品の機会損失は8。噂が外れて機会が消える盤面では、別候補の即出荷14が試作品のあと8と噂への即出荷0を上回る。噂への即出荷も機会損失8を記録する。機会が消えない盤面では、試作品のあと16が即出荷の当たり14と外れ0を上回る。試作品の報酬2が残り、機会損失は0。

固定4盤面の仮説比較であり、本番の面白さや市場予測の証明ではない。次は試作品報酬、遅れた出荷報酬、候補数の感度を見る。

## 本番境界と検証

製品の販売、勝敗、画面更新による反応の引き直しへは接続しない。閲覧順で結果は変わらない。通常の編成、勝敗、SPEC、保存、ruleset、固定トラック、WebGL停止契約へ接続しない。本番採用時は試作品済みの保存、閲覧から真の需要を除く契約、完成報酬と機会損失の分離を別Issueに分割する。version 1の信頼済み内部JSONには再現のため真の需要を含める。外部入力検証と通常保存互換は対象外。

`demand-probe-comparison.json` に初期状態、入力列、試作品報酬、機会損失、差引を記録した。対象ユニット、毎入力のJSON保存再開と再生一致、型チェック、lint、format:checkを検証する。UI/Pixiの変更はなく、E2Eとgalleryは対象外。
