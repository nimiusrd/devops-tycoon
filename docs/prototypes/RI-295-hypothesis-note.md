# RI-295 開始前の仮説メモ

親: #548 / Issue: #691（元案143）

## 判断と最小スコープ

- プレイヤーはタイトルで「今回の狙い」を1行で書き、決着画面でその仮説を続けるか変えるかを振り返る。
- 開始前の仮説はラン開始時点の内容で固定し、開始後は変更できない。決着後の追記は「終了後の振り返り」として別欄・別時刻で残す。
- メモは IndexedDB の専用 store（`hypothesisNote`）に1件だけ保存する。メタ進行・開始レシピ・ラン途中セーブ・リプレイには含めない。

## 受入条件との対応

| 受入条件 | 実装 |
| --- | --- |
| 空欄でも開始でき、読む・編集するだけで seed や候補が変わらない | 欄は任意。メモは `RunEngine` へ渡さず、同じ seed の完走結果が一致することをユニットテストで確認 |
| 記入・変更の時点を区別し、終了後の追記を開始前の仮説として見せない | `beforeStart` と `reflection` を別エントリにし、それぞれ記入時刻を持つ。開始のたびに前回の仮説を外す |
| 勝敗・ポイント・称号判定へ影響しない | 判定・報酬のコードはメモを参照しない |
| 書き出しに含めるかを選べ、長さ上限と HTML 文字列の安全な表示を守る | 再現情報のコピーは既定で含めず、チェック時だけ `hypothesisNote` を末尾に付ける。1行・120コードポイントに整え、制御文字を落とす。表示は React のテキストとしてだけ描画する |

## レビュー後の境界

- 読み込みが終わる前の開始・編集は、保存済みレコードの上に重ねる。空の初期値で端末を上書きしない。
- 仮説の鍵にはシナリオを含める。途中セーブの取り込みに成功したときは関連を外し、別ランの決着画面へ出さない。
- 保存は世代を見て、このタブが変えた欄だけを書く。別タブの仮説を、下書きの1文字編集で消さない。
- 仮説が空でも、固定処理の保存失敗は決着画面に出す。

## 保存失敗時

保存に失敗してもゲームは止めず、このセッション中は表示したまま「メモを端末に保存できませんでした」と欄の下に出す。次の保存に成功すると案内は消える。メタ・途中セーブのような進行ブロックや常駐バナーの対象にはしない。

## 結論

- 採用（最小スコープ）。開始前の仮説と終了後の振り返りを分ける記録契約を本番へ入れる。
- 保留: ラン中の閲覧、複数ラン分の履歴、リプレイ共有への同梱。複数件の履歴は RI-293（会社ビルドの履歴帳）の結果と合わせて判断する。
- 注意: 共通 DB の version を 5 に上げる。古いバージョンを開いたままの別タブがあると、新しいタブの初回 upgrade は待たされる（version 4 の追加時と同じ前提）。
