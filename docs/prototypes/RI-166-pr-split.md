# RI-166: 本当に分かれるPR

対象 #562 / 親 #548。結論: **部分出荷の仮説を限定採用、本番統合は保留**。一因子の固定戦略比較を追加しても本番採用は判断しない。人間のプレイ評価は未実施。

## 固定盤面とルール

通常ランから隔離した純TS試作。seed `RI-166` は盤面識別子であり乱数は使用しない。1担当・初期集中力6、親の総仕事6・投入済み2・残り4、総価値12。期末3/10tickの各盤面で単一PRと分割を比較。集中力1と価値1を等価とする差引指標は暫定であり、本番評価式ではない。

分割は集中力2を払い、親を履歴として残して子2件（各仕事3/価値4）と統合1件（仕事2/価値4）を生成する。投入済み仕事は巻き戻して廃棄し、追加の総仕事は8。操作自体はtickを進めず、作業は1tickで1工数。親の価値は退役後に加算しない。単一PRの完成条件は残工数0、分割の全完成は子2件＋統合のDone。子1件だけでも価値4を出荷できる。

親子IDと統合依存を保存。採番は単調増加し既存IDを回避。退役・Done・子の再分割、資源不足、未知ID、期末は無消費で拒否。未完成の子がある統合作業も拒否。親を分割後に作業して価値を二重取りできない。

統合失敗の比較盤面では初回統合だけ2工数の再確認が必要。統合価値4を保留するが出荷済み子の価値8は維持し、再確認完了時に総価値12になる。失敗有無は開始前に公開する固定条件で、実事故抽選は再現しない。未完成仕事は期末残工数として記録する。

## 一因子ずつの反転

同じ初期資源のまま、次の一つだけを動かす。方針は固定で、残りtickを見て分割を早める適応は入れない。人間のプレイ評価はしていない。差引は利用可能価値から「集中力消費 × 代替価値」を引いた値で、代替価値の基準は1。本番評価式ではない。出荷済みの子の台帳価値は消さない。未完成は期末の残工数として残す。入力列と結果は `pr-split-factor-comparison.json` にあり、テストが再計算する。

基準水準（独立点4、再作業0、担当1、期間1、遅延0、代替価値1）は、期末3が分割の差引2、期末10が単一の差引12対10、という初回の優劣に戻る。

次に解く不確実性: 固定戦略では上記の境界で期末3の分割優位が崩れるが、プレイヤーがその境界を盤面から読み取って単一PRと分割を切り替えられるかは未検証である。

## 本番境界と検証

現行splitPrのsplit印・HP/士気消費や#536の操作説明を変更しない。通常Task、SPEC、ruleset、固定トラック、勝敗、WebGL停止契約は不変。感度比較も通常ラン、保存、rulesetへ接続しない。本番採用時は親子IDの保存マイグレーション、入力リプレイ、担当・工程遷移・UIと部分出荷価値を別Issueで設計しrulesetを更新する。試作version 1は信頼済みJSONの内部保存再開のみ対応し、感度用の任意の再作業工数と同時作業入力もその内部形に限る。
